## ✨ Overview

A clean and interactive **birthday countdown timer** designed to track every second until the next birthday.

The project combines a responsive glassmorphic interface with real-time countdown calculations, automatic timezone detection, and a visual indicator showing the progress of the current birthday cycle.

**No build tools. No dependencies. No setup hassle.**

---

## 🌟 Features

### ⏳ Live Countdown

Track the remaining time with precise:

**Days · Hours · Minutes · Seconds**

The countdown updates automatically in real time.

### 📈 Birthday Year Progress

A dynamic progress indicator shows how much of the current birthday cycle has already passed.

### 🌍 Timezone Aware

The application automatically detects the visitor's browser timezone.

Examples:

* 🇮🇳 **India Standard Time — IST (UTC+5:30)**
* 🇬🇧 **British Time**
* 🇺🇸 **US Timezones**
* 🌐 **UTC**
* And other browser-supported timezones

No manual timezone configuration is required.

### 💎 Modern Interface

Built with a clean, premium aesthetic featuring:

* Glassmorphism
* Responsive layout
* Smooth visual transitions
* Minimal UI
* Mobile-friendly design

### ⚡ Zero Build Step

The entire application runs directly in the browser.

No:

```text
npm install
npm run build
webpack
vite
node_modules
```

Just open the HTML file and you're ready to go.

## 💻 Run Locally

### Clone the repository

```bash
git clone <your-repository-url>
cd birthday-countdown
```

### Option 1 — Open directly

Simply open:

```text
index.html
```

in your browser.

### Option 2 — Using `serve`

```bash
npx serve .
```

### Option 3 — Using Python

```bash
python3 -m http.server
```

Then open the local address provided by the server.

## 🌍 Timezone Handling

The countdown uses the visitor's **local browser timezone** rather than assuming a fixed location.

For example, a visitor in Mumbai will automatically use:

```text
Asia/Kolkata
UTC+05:30
IST
```

while visitors in other regions will see the countdown according to their own local timezone.
